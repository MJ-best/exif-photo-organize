**확대한 채로 넘기기** — 사진을 100% 확대하고 다음 사진으로 넘겨도 확대가 그대로 남습니다. 스페이스를 두 번 누르면 사진 한가운데가 바로 100% 로 확대됩니다.

## 내려받기

| 쓰는 컴퓨터 | 받을 파일 |
|---|---|
| **맥 (Apple Silicon · Intel 모두)** | `photo-organize-macos-universal.dmg` (또는 `.zip`) — 안에 **LOUPE.app** |
| Windows 10/11 (64비트) | `photo-organize-windows-x86_64.zip` |
| Linux (x86_64) | `photo-organize-linux-x86_64.tar.gz` |

**맥에서 경고 없이 바로 설치 · 업데이트하기** (터미널):

```bash
osascript -e 'quit app "LOUPE"' 2>/dev/null; curl -fL https://github.com/MJ-best/exif-photo-organize/releases/latest/download/photo-organize-macos-universal.zip -o /tmp/photo-organize.zip && rm -rf "/Applications/LOUPE.app" && ditto -x -k /tmp/photo-organize.zip /Applications && open "/Applications/LOUPE.app"
```

브라우저로 받았다면 `.dmg` 의 **LOUPE** 를 Applications 로 끌어 놓으세요. 처음 열 때 *"악성 코드가 없음을 확인할 수 없습니다"* 창에서 **완료** → **시스템 설정 → 개인정보 보호 및 보안** 맨 아래 **그래도 열기** 를 누르세요. Apple 공증을 받지 않은 앱이면 나오는 문구이고, 무엇이 발견된 것은 아닙니다. [자세히](https://github.com/MJ-best/exif-photo-organize#macos-맥북--권장)

## 바뀐 것: 사진 보기의 확대

- **확대가 다음 사진에도 그대로** — `Z` · 클릭 · 스페이스 두 번으로 100% 확대한 뒤 **← →**, 필름 스트립, 별점 뒤 자동 넘김으로 넘겨도 **같은 자리가 확대된 채로** 나옵니다. 연사에서 눈 · 초점이 맞았는지 같은 자리를 나란히 비교하기 좋습니다. 다시 클릭하거나 `Z` 를 누르면 전체 보기로 돌아가고, 그때부터는 다음 사진도 전체 보기입니다.
- **스페이스 두 번** (빠르게) — 사진 **한가운데를 100%** 로 확대합니다. 다시 두 번 누르면 전체 보기. 그리드에서 두 번 누르면 사진을 열면서 바로 확대합니다.
- **스페이스 한 번** 은 지금처럼 크게 보기 ↔ 돌아가기입니다. 두 번째 누름을 기다리느라 *돌아가기* 만 0.3초 늦게 바뀝니다. 스페이스를 누르고 있어도 화면이 계속 바뀌지 않습니다.
- 확대한 채로 볼 때는 다음 사진의 원본 해상도를 미리 불러 두어, 넘기자마자 선명하게 보입니다.
- 그리드에서 사진을 새로 열면 늘 전체 보기로 시작합니다.

라이브러리 · 별점 · 학습 기록은 그대로 이어집니다. 셀렉 엔진은 바뀌지 않았습니다 (0.6.0 과 같음).

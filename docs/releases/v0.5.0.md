**사진 지우기** — 셀렉이 끝나 정말 필요 없는 사진을 휴지통으로 옮길 수 있습니다. 내가 거절했던 기록은 셀렉 도우미가 계속 배웁니다.

## 내려받기

| 쓰는 컴퓨터 | 받을 파일 |
|---|---|
| **맥 (Apple Silicon · Intel 모두)** | `photo-organize-macos-universal.dmg` (또는 `.zip`) |
| Windows 10/11 (64비트) | `photo-organize-windows-x86_64.zip` |
| Linux (x86_64) | `photo-organize-linux-x86_64.tar.gz` |

**맥에서 경고 없이 바로 설치 · 업데이트하기** (터미널):

```bash
osascript -e 'quit app "Photo Organize"' 2>/dev/null; curl -fL https://github.com/MJ-best/exif-photo-organize/releases/latest/download/photo-organize-macos-universal.zip -o /tmp/photo-organize.zip && rm -rf "/Applications/Photo Organize.app" && ditto -x -k /tmp/photo-organize.zip /Applications && open "/Applications/Photo Organize.app"
```

브라우저로 받았다면 처음 열 때 *"악성 코드가 없음을 확인할 수 없습니다"* 창에서 **완료** → **시스템 설정 → 개인정보 보호 및 보안** 맨 아래 **그래도 열기** 를 누르세요. Apple 공증을 받지 않은 앱이면 나오는 문구이고, 무엇이 발견된 것은 아닙니다. [자세히](https://github.com/MJ-best/exif-photo-organize#macos-맥북--권장)

## 새 기능: 휴지통으로 옮기기

거절(B컷)은 지금처럼 표시일 뿐이고, 파일은 그대로 남습니다. 다 고른 뒤 지우고 싶을 때:

- 사이드바 **거절 (B컷)** 을 열면 위에 **거절한 사진 n장** 바가 뜹니다. **n장 휴지통으로…** 를 누르면 한 번에 지웁니다.
- 아무 사진이나 고른 뒤(여러 장도) **Delete** / **⌫** (맥은 **⌘⌫** 도), 또는 우클릭 → **휴지통으로 옮기기…**. 크게 보고 있으면 지운 뒤 다음 사진으로 넘어갑니다.
- 지우기 전에 **사진 몇 장 · 파일 몇 개 · 용량**을 보여 주고 묻습니다 (Enter 확인, Esc 취소).
- 한 사진의 **RAW · JPEG · XMP** 와 작품 폴더의 복사본까지 함께 옮겨 쌍이 깨지지 않습니다.
- 바로 지우지 않고 **시스템 휴지통**으로 옮깁니다. 비우기 전에는 되살릴 수 있고, 되살린 뒤 **폴더에서 가져오기…** 로 넣으면 별점도 XMP 에서 돌아옵니다.
- 휴지통이 없는 드라이브(일부 USB 메모리 · SD 카드)에서는 지우지 않고 그대로 두며, 몇 장을 못 옮겼는지 알려 줍니다.

**학습 기록은 남습니다.** 지운 사진에 매겼던 거절 · 픽 · 별점과 그 사진의 측정값은 카탈로그에 따로 남아, 셀렉 도우미가 *"이런 사진은 B컷"* 이라고 배운 것을 잊지 않습니다. 거절한 사진을 정리해도 학습된 기준과 **내 셀렉 정확도**가 그대로 유지됩니다. (사진 · 썸네일은 남지 않고, 연사 묶음 비교에서도 빠집니다.)

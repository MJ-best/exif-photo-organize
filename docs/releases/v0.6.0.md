**Photo Organize 가 LOUPE 로 이름을 바꿨습니다** — 사진가의 서랍, 사진을 고르는 시간. 하는 일은 같고, 라이브러리 · 별점 · 학습 기록도 그대로 이어집니다.

## 내려받기

| 쓰는 컴퓨터 | 받을 파일 |
|---|---|
| **맥 (Apple Silicon · Intel 모두)** | `photo-organize-macos-universal.dmg` (또는 `.zip`) — 안에 **LOUPE.app** |
| Windows 10/11 (64비트) | `photo-organize-windows-x86_64.zip` |
| Linux (x86_64) | `photo-organize-linux-x86_64.tar.gz` |

**맥에서 경고 없이 바로 설치 · 업데이트하기** (터미널) — 이전 이름의 앱(`Photo Organize.app`)도 함께 정리합니다:

```bash
osascript -e 'quit app "LOUPE"' 2>/dev/null; osascript -e 'quit app "Photo Organize"' 2>/dev/null; curl -fL https://github.com/MJ-best/exif-photo-organize/releases/latest/download/photo-organize-macos-universal.zip -o /tmp/photo-organize.zip && rm -rf "/Applications/LOUPE.app" "/Applications/Photo Organize.app" && ditto -x -k /tmp/photo-organize.zip /Applications && open "/Applications/LOUPE.app"
```

브라우저로 받았다면 `.dmg` 의 **LOUPE** 를 Applications 로 끌어 놓고, 예전 **Photo Organize** 는 휴지통으로 옮기세요. 처음 열 때 *"악성 코드가 없음을 확인할 수 없습니다"* 창에서 **완료** → **시스템 설정 → 개인정보 보호 및 보안** 맨 아래 **그래도 열기** 를 누르세요. Apple 공증을 받지 않은 앱이면 나오는 문구이고, 무엇이 발견된 것은 아닙니다. [자세히](https://github.com/MJ-best/exif-photo-organize#macos-맥북--권장)

## 바뀐 것: 이름

- 앱 이름 · 창 제목 · 맥의 앱(`LOUPE.app`) · 윈도우 실행 파일 정보가 **LOUPE** 로 바뀌었습니다.
- **그대로인 것**: 라이브러리 폴더와 카탈로그(`.photo-organize`), 앱 설정, XMP 사이드카, 내려받는 파일 이름. 업데이트해도 다시 가져오거나 다시 학습할 필요가 없습니다.
- 맥에서는 앱의 이름이 바뀌어, 처음 열 때 *이동식 볼륨* 접근을 다시 물을 수 있습니다. **허용**을 누르세요.

## 안드로이드 (미리 보기)

태블릿 우선의 안드로이드 셀렉 앱을 준비하고 있습니다. SD 카드나 USB 카드 리더로 가져와 셀렉 도우미로 B컷을 걸러 두고, 위로 밀면 픽 · 아래로 밀면 거절합니다. Google Play 출시 전이라 이 릴리스에는 들어 있지 않고, 써 보려면 [Actions → android](https://github.com/MJ-best/exif-photo-organize/actions/workflows/android.yml) 의 `photo-organize-android` 아티팩트에서 테스트용 APK 를 받으세요 ([자세히](https://github.com/MJ-best/exif-photo-organize/blob/main/docs/play-store/README.md)).

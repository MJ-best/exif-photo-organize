**셀렉 도우미가 구도까지 봅니다** — 사람과 배경을 나눠 3분할 · 헤드룸 · 시선 앞 공간 · 머리 뒤 기둥 · 수평을 재고, 왜 B컷인지 · 왜 A컷인지 근거를 보여 줍니다. 내가 즐겨 쓰는 구도도 배웁니다.

## 내려받기

| 쓰는 컴퓨터 | 받을 파일 |
|---|---|
| **맥 (Apple Silicon · Intel 모두)** | `photo-organize-macos-universal.dmg` (또는 `.zip`) — 안에 **LOUPE.app** |
| Windows 10/11 (64비트) | `photo-organize-windows-x86_64.zip` |
| Linux (x86_64) | `photo-organize-linux-x86_64.tar.gz` |

**맥에서 경고 없이 바로 설치 · 업데이트하기** (터미널):

```bash
osascript -e 'quit app "LOUPE"' 2>/dev/null; curl -fL https://github.com/MJ-best/exif-photo-organize/releases/latest/download/photo-organize-macos-universal.zip -o /tmp/photo-organize.zip && rm -rf "/Applications/LOUPE.app" && ditto -x -k /tmp/photo-organize.zip /Applications && open "/Applications/LOUPE.app"
```

브라우저로 받았다면 `.dmg` 의 **LOUPE** 를 Applications 로 끌어 놓으세요. 처음 열 때 *"악성 코드가 없음을 확인할 수 없습니다"* 창에서 **완료** → **시스템 설정 → 개인정보 보호 및 보안** 맨 아래 **그래도 열기** 를 누르세요. Apple 공증을 받지 않은 앱이면 나오는 문구이고, 무엇이 발견된 것은 아닙니다. [자세히](https://github.com/MJ-best/exif-photo-organize#macos-맥북--권장)

## 새 기능: 구도 · 프레이밍

사진마다 **사람과 배경을 픽셀 단위로 나누고**(인물 분할 신경망, 앱 안에서 실행 — 사진은 밖으로 나가지 않습니다) 인물 사진의 구도 기본을 잽니다.

| 기준 | 무엇을 보나 |
|---|---|
| **3분할** | 눈높이가 위 1/3 선에, 얼굴이 세로 3분할 선에 있는지 (풍경은 수평선이 화면을 반으로 가르는지) |
| **헤드룸** | 머리 꼭대기(머리카락 · 모자 끝)부터 프레임 위까지의 여백 — 머리가 닿거나 잘림, 또는 위가 텅 빔. 클로즈업은 머리를 자르는 게 정상이라 눈높이만 봄 |
| **시선 앞 공간** | 얼굴이 돌아간 방향(눈과 코의 위치)으로 보는 쪽에 공간이 있는지 |
| **머리 뒤 기둥 · 선** | 배경에서 머리 위로 솟은 세로선(기둥 · 나무 · 모서리), 머리 · 목을 가로지르는 가로선 |
| **수평 · 수직 기울어짐** | 가운데 세로선(건물 · 문틀), 없으면 긴 수평선의 기울기 |
| **얼굴이 프레임에 잘림** | 얼굴 일부가 프레임 밖 (클로즈업에서 이마 위를 자른 것은 제외) |
| **초점이 배경에** | 인물과 배경의 가장자리 선명도 비교 — 핀이 뒤로 간 경우 |

- **근거를 보여 줍니다.** 정보 패널의 **구도** 칸에 기준마다 잰 값과 판정(초록 · 주황)이 나옵니다 — *"헤드룸: 머리 위 여백 3%"*, *"시선 앞 공간: 오른쪽을 봄 · 앞 18% / 뒤 82%"* 처럼.
- **크게 보기에서 `G`** (위쪽 막대의 격자 버튼): 3분할 선 · 피사체 · 눈 위치 · 헤드룸 · 시선 방향 · 머리 뒤 선 · 기울어진 선을 사진 위에 그립니다.
- **A컷 후보에도 근거**: *눈에 초점 · 3분할 구도 · 헤드룸 알맞음 · 시선 앞 여백 · 수평이 맞음 · 배경이 깔끔하게 흐림 · 연사 중 베스트 · 내가 좋아하는 구도*.

## 내가 즐겨 쓰는 구도를 배웁니다

내가 남긴 사진(픽 · ★3+) 하나하나를 구도의 예로 기억합니다. 여러 구도를 쓰면(타이트한 인물, 3분할 반신, 넓은 화면의 전신…) 여러 무리로 기억하고, **그 어느 것과도 다르게 찍힌 사진**을 B컷 쪽으로 올립니다(이유: *내 구도와 다름*). A컷이 8장 이상 모이면 동작합니다. 각 구도 기준의 무게도 내 셀렉에서 배웁니다 — 가운데 구도를 늘 남기는 사람에게는 3분할이 점점 덜 중요해집니다.

## 기준을 직접 끄기

**설정 → 셀렉 도우미 → B컷으로 볼 기준**에서 기준마다 켜고 끕니다(초점 · 노출 · 구도 · 취향 전부). 끈 기준은 B컷 판단 · 학습 · 근거 표시에서 모두 빠집니다. 예: 가운데 구도를 즐겨 쓴다면 **3분할**, 클로즈업으로 머리를 자르는 스타일이라면 **헤드룸**.

## 그 밖에

- 무늬 많은 배경(국기 · 나뭇잎) 앞의 인물을 *"얼굴 초점 빗나감"* 으로 잘못 보던 경우를 고쳤습니다 — 얼굴이 흐린지를 디테일 양이 아니라 가장자리 선명도로 확인합니다.
- **업데이트하면 모든 사진을 한 번 다시 분석합니다**(최근 사진부터, 백그라운드, 사진당 0.2–0.3초). 그동안에도 셀렉 도우미는 이전 분석으로 계속 동작하고, 1,000장마다 새 분석이 반영됩니다. 별점 · 판정 · 학습 기록은 그대로입니다.
- 인물 분할 모델(PP-HumanSeg, Apache-2.0)이 들어가 앱이 6MB 커졌습니다.
- 셀렉 엔진의 이 버전은 2030-11-15 에 MIT 로 바뀝니다 ([LICENSING.md](https://github.com/MJ-best/exif-photo-organize/blob/main/LICENSING.md)).

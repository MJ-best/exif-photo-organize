**셀렉 도우미 게이지와 학습 점수 보정** — 정보 패널의 막대가 **왼쪽 `← B컷 XX%` ↔ 오른쪽 `A컷 YY% →`** 양방향 게이지로 바뀌어 한눈에 방향을 읽을 수 있고, 거절을 많이 하거나 연사를 지운 라이브러리에서 상위 A컷까지 B컷 90%대로 쏠리던 학습 점수 보정을 고쳤습니다.

## 바뀐 것

- **왼쪽(B컷) ↔ 오른쪽(A컷) 스펙트럼 게이지** — 기존 *B컷 가능성* 단일 막대는 B컷 가능성이 높을수록 오른쪽으로 차올라 직관과 반대였습니다. 이제 왼쪽은 주황색 `← B컷 XX%`, 오른쪽은 초록색 `A컷 YY% →` 로 나란히 표시되고, 막대 안의 세로 기준선(B컷 후보 기준)에서 왼쪽으로 갈수록 B컷 후보, 오른쪽으로 갈수록 A컷 쪽임을 바로 알 수 있습니다 (데스크톱 · 안드로이드 모두).
- **학습 점수 쏠림 수정 (`learn::anchor`)** — 거절(`X`)이 픽(`P` · 별점)보다 훨씬 많거나 휴지통을 비워 삭제된 연사 프레임이 많은 라이브러리에서, 기준점 보정이 미결정 사진 전체의 B컷 확률을 95% 근처로 끌어올려 상위 4% A컷 후보까지 B컷 90%대로 표시되던 문제를 고쳤습니다. 반대로 별점 위주(`A ≫ B`)로 고를 때 B컷 후보 목록이 사라지던 현상도 함께 막았습니다.
- **다시 분석하지 않고 바로 반영** — 분석 데이터는 0.7.3 과 같아 라이브러리를 열면 사진을 다시 분석하지 않고 1초 안에 새 점수로 다시 계산됩니다.

내보내기를 고치고, **용량을 줄여 내보내는 기능**을 더했습니다.

## 내려받기

| 쓰는 컴퓨터 | 받을 파일 |
|---|---|
| **맥 (Apple Silicon · Intel 모두)** | `photo-organize-macos-universal.dmg` (또는 `.zip`) |
| Windows 10/11 (64비트) | `photo-organize-windows-x86_64.zip` |
| Linux (x86_64) | `photo-organize-linux-x86_64.tar.gz` |

**맥에서 경고 없이 바로 설치하기** (터미널):

```bash
curl -fL https://github.com/MJ-best/exif-photo-organize/releases/latest/download/photo-organize-macos-universal.zip -o /tmp/photo-organize.zip && rm -rf "/Applications/Photo Organize.app" && ditto -x -k /tmp/photo-organize.zip /Applications && open "/Applications/Photo Organize.app"
```

브라우저로 받았다면 처음 열 때 *"악성 코드가 없음을 확인할 수 없습니다"* 창에서 **완료** → **시스템 설정 → 개인정보 보호 및 보안** 맨 아래 **그래도 열기** 를 누르세요 (macOS 15 부터는 우클릭 → 열기로는 열리지 않습니다). Apple 공증을 받지 않은 앱이면 나오는 문구이고, 무엇이 발견된 것은 아닙니다. [자세히](https://github.com/MJ-best/exif-photo-organize#macos-맥북--권장)

## 고친 점

- **"JPEG만" 내보내기에 RAW 원본이 섞여 나오던 문제.** JPEG 없이 RAW 만 있는 사진(RAW 로만 찍었거나 짝이 없는 RAW)은 RAW 와 `.xmp` 가 그대로 복사되고, 동영상도 함께 나왔습니다. 이제 *JPEG만* 은 사진마다 JPEG 하나만 내보냅니다 — 카메라 JPEG 를 그대로 복사하고, RAW 만 있는 사진은 RAW 안에 들어 있는 원본 크기 JPEG 로 만들어 줍니다.

## 새 기능: 작게 내보내기

그리드 우클릭 또는 여러 장 선택 → 정보 패널 → **작게…**

- 긴 변 **1080 / 2048 / 3000 / 4000px** 또는 원래 크기, 화질 **보통 / 높음 / 최고** 를 고릅니다. 대화상자에 예상 용량이 나옵니다.
- 촬영 날짜 · 카메라 · 렌즈 · 노출 정보는 남기고(휴대폰 갤러리에서도 날짜순으로 정리됨) **위치(GPS)는 넣지 않습니다.** 세로 사진은 바로 세워 저장합니다.
- 예 (24MP · 9.3 MB 고화질 JPEG 테스트 사진): 2048px · 높음 ≈ 0.4 MB, 1080px · 보통 ≈ 0.13 MB, 원래 크기 · 높음 ≈ 3.2 MB.
- 원래 크기로 했는데 원본보다 작아지지 않는 사진은 원본 화질을 그대로 두고 위치 정보만 뺍니다 — 내보낸 파일이 원본보다 커지지 않습니다.
- 진행 상황은 사이드바 아래에 보입니다 (누르면 중지). 원본은 건드리지 않습니다.

## 여러 장을 한 번에 보낼 때

여러 장을 선택해 우클릭(또는 정보 패널) → **내보내기** 창에서 형식(원본 전체 · JPEG만 · 작게)과 보내는 방법을 고릅니다.

- **ZIP 으로 묶기**: 파일 하나로 보내기 좋게 묶습니다. **25 MB / 100 MB / 1 GB 씩 나누기**를 고르면 `이름 (1).zip`, `이름 (2).zip` … 으로 나뉘고, 각각 따로 열려서 메일 · 메신저에 하나씩 보내면 됩니다. 한글 파일 이름도 그대로 보입니다.
- **파일 이름 앞에 촬영 일시 붙이기** (`2026-10-03_091500_IMG_0001.jpg`): 받는 쪽에서도 찍은 순서대로 정렬되고, 여러 카메라의 같은 번호도 겹치지 않습니다.
- 사진은 항상 **찍은 순서대로** 내보내고, 같은 이름은 `_1` 로 구분합니다 (RAW · JPEG · `.xmp` 는 같은 이름 유지).
- 창에 예상 용량 · ZIP 개수 · 빠지는 동영상/HEIF 개수가 미리 나옵니다.
- 큰 사진을 많이 내보내도 메모리가 넘치지 않도록 원래 크기는 두 장씩, 줄일 때는 여러 코어로 만듭니다. 예: 24MP 사진 30장 → 2048px ZIP 11 MB 4초 (4코어).
- 명령줄: `photoorg export <라이브러리> <폴더> --small 2048 --zip "제주 여행" --split 25 --date-names [--min-rating 4]`

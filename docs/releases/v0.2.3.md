**작품 폴더** — 셀렉한 작품 사진을 한 폴더로 모아 라이트룸 등에서 바로 편집할 수 있습니다.

## 내려받기

| 쓰는 컴퓨터 | 받을 파일 |
|---|---|
| **맥 (Apple Silicon · Intel 모두)** | `photo-organize-macos-universal.dmg` (또는 `.zip`) |
| Windows 10/11 (64비트) | `photo-organize-windows-x86_64.zip` |
| Linux (x86_64) | `photo-organize-linux-x86_64.tar.gz` |

**맥에서 경고 없이 바로 설치 · 업데이트하기** (터미널):

```bash
osascript -e 'quit app "Photo Organize"' 2>/dev/null; curl -fL https://github.com/MJ-best/exif-photo-organize/releases/latest/download/photo-organize-macos-universal.zip -o /tmp/photo-organize.zip && rm -rf "/Applications/Photo Organize.app" && ditto -x -k /tmp/photo-organize.zip /Applications && open "/Applications/Photo Organize.app"
```

브라우저로 받았다면 처음 열 때 *"악성 코드가 없음을 확인할 수 없습니다"* 창에서 **완료** → **시스템 설정 → 개인정보 보호 및 보안** 맨 아래 **그래도 열기** 를 누르세요. Apple 공증을 받지 않은 앱이면 나오는 문구이고, 무엇이 발견된 것은 아닙니다. [자세히](https://github.com/MJ-best/exif-photo-organize#macos-맥북--권장)

## 새 기능: 작품 폴더

```
① 셀렉 (별점 · 픽)  →  ② 작품 테마 붙이기 (⇧1~9)  →  ③ 작품 폴더로 모으기  →  ④ 라이트룸에서 폴더째 가져와 편집
```

작품을 누르면 사진 위에 **작품 폴더** 바가 보입니다. **작품 폴더로 모으기…** 를 누르면 작품의 사진이 라이브러리 안 `작품/<작품 이름>/<테마>/` 에 모입니다 (RAW · JPEG · XMP 함께).

- **옮기기** (기본): 날짜 폴더에서 작품 폴더로 옮깁니다. 사진은 한 곳에만 있어 용량이 늘지 않고, 이 앱에서는 날짜별로 그대로 보입니다. 원래 자리를 기억하므로 작품 우클릭 → **날짜 폴더로 되돌리기** 로 언제든 되돌릴 수 있습니다.
- **복사**: 날짜 폴더의 원본은 보관용으로 그대로 두고 작품 폴더에 복사본을 만듭니다.
- 라이트룸에서 폴더를 **추가(Add)** 로 가져오면 별점과 테마 키워드(`바다 사진집|새벽`)가 그대로 보입니다.
- 테마가 여러 개인 사진은 **첫 번째 테마 폴더에 한 번만** 들어갑니다 — 편집할 때 같은 사진이 두 번 나오지 않습니다 (모든 테마는 키워드로 남음).
- **다시 모으면 새로 고른 사진만** 더합니다. 바에 *"13장 모음 · 새로 모을 사진 2장"* 처럼 보입니다. 이미 모은 사진은 테마가 바뀌어도 그 자리에 둡니다 (라이트룸이 사진을 놓치지 않도록).
- 테마를 빼서 작품에서 빠진 사진이 폴더에 남아 있으면 바에 표시되고, 누르면 날짜 폴더로 되돌립니다.
- 작품 · 테마 이름을 바꾸면 폴더 이름도 함께 바뀝니다. 라이트룸에 이미 가져왔다면 라이트룸에서 폴더 위치를 다시 지정하세요.
- 같은 이름(두 카메라의 `IMG_0001`)은 RAW · JPEG · XMP 가 함께 `IMG_0001_1` 로 바뀌고, 한 사진의 파일 중 하나라도 옮기지 못하면 그 사진은 원래 자리로 돌아갑니다.

## 고친 점

- 작품 · 테마 대화상자가 앞서 연 창의 크기를 물려받아 빈 공간이 생기던 문제.

## 업데이트할 때

기존 라이브러리는 처음 열 때 자동으로 새 형식으로 바뀝니다 (사진 · 별점 · 태그 · 작품은 그대로).

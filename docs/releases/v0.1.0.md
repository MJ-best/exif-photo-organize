SD 카드를 꽂으면 외장 하드로 옮기면서 EXIF 기준으로 자동 정리하고, F1~F5 별점으로 셀렉하는 사진 정리 앱의 첫 릴리스입니다.

## 내려받기

| 쓰는 컴퓨터 | 받을 파일 |
|---|---|
| **맥 (Apple Silicon M1~M4 · Intel 모두)** | `photo-organize-macos-universal.dmg` (또는 같은 내용의 `.zip`) |
| Windows 10/11 (64비트) | `photo-organize-windows-x86_64.zip` |
| Linux (x86_64) | `photo-organize-linux-x86_64.tar.gz` |

각 압축 파일에는 앱(`Photo Organize` / `photo-organize`)과 명령줄 도구 `photoorg` 가 들어 있습니다.

## 맥에서 설치하기

1. `.dmg` 를 열고 **Photo Organize** 를 **Applications** 로 끌어 놓습니다.
2. 처음 한 번은 **우클릭 → 열기 → 열기** 로 실행합니다. (Apple 개발자 서명이 없는 앱이라 더블클릭하면 막힙니다)
   macOS 15 이상에서는 한 번 실행을 시도한 뒤 **시스템 설정 → 개인정보 보호 및 보안 → "그래도 열기"** 를 누르세요.
3. *"손상되었기 때문에 열 수 없습니다"* 가 나오면 터미널에서:
   `xattr -dr com.apple.quarantine "/Applications/Photo Organize.app"`
4. SD 카드 · 외장 하드 접근을 묻는 창이 뜨면 **허용**합니다.

Windows 에서 *"Windows의 PC 보호"* 창이 뜨면 **추가 정보 → 실행** 을 누르세요.

## 이번 버전에 들어 있는 것

- **카드 자동 감지 → 가져오기 화면**: 새 사진 수 · 용량 · RAW+JPEG 쌍 · 촬영 기간 · 카메라 요약, 이미 가져온 사진은 `가져옴` 표시
- **복사와 정리를 한 번에**: 날짜별 폴더(템플릿 선택), BLAKE3 체크섬 검증, 임시 파일 → 이름 변경으로 안전한 복사, 중복 자동 건너뛰기
- **RAW + JPEG 를 한 장으로**: 듀얼 슬롯 카드, `RAW/` 하위 폴더도 자동으로 묶음, 정보 패널에서 RAW 원본 / 카메라 JPEG 구분
- **「사진」 앱 스타일 갤러리**: 연 · 월 · 일 · 모든 사진, 크게 보기(100% 확대 · 필름 스트립), 정보 패널, 다크 · 라이트 테마
- **F1~F5 별점 셀렉**: 여러 장 한 번에, 별점 후 다음 사진으로(옵션), XMP 사이드카로 Lightroom · Capture One 호환
- **EXIF 필터**: 카메라 · 렌즈 · ISO · 초점거리 · 조리개 · 셔터 · 별점 · 형식 · 태그, 항목마다 사진 수 표시
- **자동 태그**(화각 · 감도 · 시간대 · 계절 등), 직접 태그, CSV 내보내기, 고른 사진 내보내기(원본 / JPEG 만)
- 명령줄 도구 `photoorg` (scan · import · list · stats · rate · export-csv)

자세한 사용법은 [README](https://github.com/MJ-best/exif-photo-organize#readme) 를 보세요.

## 알려진 제한

- HEIF/HEIC 와 동영상은 정리 · 필터 · 별점은 되지만 썸네일 대신 아이콘이 표시됩니다.
- 앱에 Apple · Microsoft 코드 서명이 없어 처음 실행할 때 한 번 허용이 필요합니다.
- 첫 릴리스라 실제 맥 · 윈도우 기기와 다양한 카메라의 RAW 파일에서는 아직 충분히 검증되지 않았습니다. 문제가 생기면 [Issues](https://github.com/MJ-best/exif-photo-organize/issues) 에 카메라 기종과 함께 알려 주세요.
